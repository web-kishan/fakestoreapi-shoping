🛒 FakeStore API Shopping App

A simple Shopping Web Application built using HTML, JavaScript, Bootstrap, and the FakeStore API.
Users can browse products, filter by category, and add items to a cart.

🚀 Features
📦 Fetch products from FakeStore API
🗂️ Filter products by category
🛒 Add items to cart
🔢 Dynamic cart item count
👀 View cart items in a modal
📱 Responsive design using Bootstrap

🧑‍💻 Technologies Used
HTML5
CSS3 (Bootstrap 5)
JavaScript (Vanilla JS)
FakeStore API

🌐 API Used
https://fakestoreapi.com/products
https://fakestoreapi.com/products/categories
